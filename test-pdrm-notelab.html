🧠 PDRM 2.0 Framework

Each concept block generates structured analysis fields for enhanced comprehension:

🎯 Pattern

Automatically detected reading pattern with confidence score (e.g., Definition-Example, Cause-Effect, Problem-Solution)

⚖️ Decision Rule

Framework for applying this pattern to similar content, based on pattern-specific rules and context

💡 Why It Works

Explanation of pattern effectiveness including cognitive alignment and structural reasoning

🔍 Understanding Detail

Manually editable deep analysis points with automatic enhancement suggestions

🎯 Application

Practical usage examples and practice tips for applying the pattern to other texts

🔗 Cross-Link

Related patterns and concepts, automatically generated and manually expandable

🤔 Reflection Prompt

Self-assessment questions to reinforce learning and pattern recognition skills

⏱️ Smart-Hour Protocol

Focus Block Timer

50:00

50-minute focus sessions with structured learning checklist

Focus Session Checklist:

  • Define Pattern - Identify the reading pattern
  • Write Rule - Create decision framework
  • Explain Why - Understand pattern effectiveness
  • Review Detail - Enhance understanding points
  • Reflect - Complete self-assessment

Post-session: Rate clarity (1-5) and log insights for progress tracking
